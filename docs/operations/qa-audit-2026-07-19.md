  table creation are disabled only in unit fixtures.

## Initial failures and repairs

- Ruff command failed because Ruff is absent from the active interpreter.
- `pytest-cov` is listed in requirements but absent from the active interpreter;
  no local coverage percentage is claimed.
- Frontend tests existed but Vitest, Testing Library, Playwright, configs, and
  npm scripts were missing. Dependencies/configuration were added.
- ESLint initially reported seven errors. Unsafe `any`, reconnect callback
  lifecycle, unescaped JSX quotes, and unused code were corrected.
- MetricCard unit assertions referenced obsolete Tailwind classes and were
  updated to the component's current semantic glow class.
- Playwright assertions referenced stale page copy and `SIM-FD001`; they now
  use accessible roles and assert public `ISM-CNC-001` display while allowing
  internal `FD001` routing.
- RAG tests attempted a Hugging Face download and used an inaccessible global
  Windows temp directory. The unit boundary now mocks only the external model
  loader, and the suite uses a workspace base temp.
- Unit application startup previously called configured database table creation.
  The fixture now prevents any configured application DB mutation.

## Outstanding production blockers

1. Joblib artifacts were serialized with scikit-learn 1.9.0, but the verified
   runtime is 1.8.0. Pin the serving image to the training version or retrain and
   republish artifacts with provenance/checksums before release.
2. `pytest-cov` and Ruff must be installed in the active developer environment;
   CI installs Ruff separately, but local parity is not currently guaranteed.
3. The RAG suite has four explicit skips. Review skip reasons before treating the
   RAG pipeline as fully production-certified.
4. Docker emitted an unreadable user-level Docker config warning on this host,
   although Compose validation itself exited successfully.
5. The current suite does not yet exercise PostgreSQL migrations or a real
   PostgreSQL service. SQLite success is not PostgreSQL certification.
6. Dependency installation reported two moderate npm vulnerabilities. Review
   `npm audit` and apply non-breaking upgrades before release.
